# ADR-0005: Carry-over Batching, Template Hygiene & Marker Single-Source

**Status:** Accepted
**Date:** 2026-08-19
**Supersedes:** none（实现 ADR-0004 Deferred 中的两项：3C 批量化/忽略冷却、模板占位说明；标记单一事实源为本次新增决策，不取代任何既有决策）

## Context

ADR-0004 后实测讨论确认：跨天延续仍逐条询问、`已忽略` 标注没有冷却效果（次日原样再问）；模板「搁置 / 删减」区块与象限④ 重复记账；状态标记语义同时在 SKILL.md 3B 表格与 todo.md 头部注释各写一份。三者都是日常使用中可持续感知的摩擦，成本低、价值明确，值得立即处理。

## Decisions

1. **跨天延续批量化 + 忽略冷却**
   - 步骤 3C 不再逐条问「要不要」，改为按源文件分组**批量列出**全部未完成任务，一次性询问「哪些还值得做？」，圈出的归入今日，其余统一忽略。
   - 忽略标注改为 `→ 已忽略（YYYY-MM-DD）`（带日期）；距今 ≤1 天的任务不再列入（用户主动提及才处理），>1 天可重新列出重估。
   - 兼容旧标注：无日期的 `→ 已忽略` 视同已过冷却期，正常列出。
2. **模板卫生**
   - 「搁置 / 删减」独立区块删除，象限④ 条目自带原因（`- [ ] {任务} —— 原因：{为什么今天不做}`），一处记账。
   - 模板占位符 `{星期}`、`{HH:MM}` 在 SKILL.md 步骤 7 补充填写规则（中文星期、生成时刻），不再依赖 agent 自行推断。
3. **标记定义单一事实源**
   - 状态标记的语义与建池规则只保留在 SKILL.md 步骤 3B 表格（agent 执行权威）。
   - `{todo_filename}`（todo.md）头部注释压缩为「写法 + 标记名清单 + 指向 SKILL.md 步骤 3B」，并清除已过期的示例注释块，避免示例行被误读进任务池。

## Rationale

- 批量询问把延续环节从 1 次/条压缩为 1 次/天，与 ADR-0004 的快速模式批量圈选同一原则：压缩交互、保留决策质量。
- 带日期的忽略标注使「忽略」成为有冷却的显式决定，而非每日常规重问；仅冷却 1 天保证任务不会因一次忽略而永久消失。
- 象限④ 自带原因消除了模板中同一任务记账两遍的结构性重复（2026-07-30.md 实测出现）。
- 标记语义收敛到 SKILL.md 一处，todo.md 头部只留用户面提示，避免两处文档漂移。

## Deferred

- 归档四选项增加「保持原样」（ADR-0004 遗留）。
- 快速模式激进版（跳过步骤 4 直接选 3 条，接受四象限总览缺失）（ADR-0004 遗留）。
- 收尾仪式推广到「最近一次运行日」（跳过一天再跑时的场景）。
- evals 评估基线（普通早间 / 快速模式 / 跳过一天 / 归档边界 / 同日重跑 五场景 with/without 对比）。
- description 触发词优化。
