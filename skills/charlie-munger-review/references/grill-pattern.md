# Grill 追问模式

Phase 2b 逐条 grill 与 Phase 3 深挖共用此模式。一次一问，跟随回答，不给价值判断，可指出深度与一致性缺口。

## 三层推进

每条偏误/深挖对象按 L1→L2→L3 推进。当前层 pass signal 满足后进入下一层。每层至少 1 问，不跳层。

**L1 理解核实**：用户能复述该偏误在自己决策中的具体表现吗？
- 问："你说中了 X 偏误——具体是决策哪一步体现的？"
- Pass signal：用户能用自己语言指出具体环节，而非复读偏误定义。

**L2 证据追问**：凭什么认为是这个偏误？有反例吗？
- 问："凭什么认为是 X，而不是 Y？有反例证据吗？"
- Pass signal：用户给出可观测证据，能区分 X 与替代假设 Y。

**L3 反思逼问**：当时若意识到这个偏误，会改变决策吗？
- 问："当时若意识到 X，你会怎么改？下次同类信号出现怎么办？"
- Pass signal：用户给出可执行的"当 X 信号时做 Y 而非 Z"教训。

## Follow-up 策略

| 用户回答 | 追问 |
|---|---|
| 模糊 | "能更具体说吗？" |
| 浅薄 | "能再深一层吗？" |
| 回避 | 换个角度重述问题 |
| 矛盾 | "你刚才说…现在又说…，这之间什么关系？" |
| 结论对但推理缺 | "你是怎么推导出这个结论的？" — 不接受无推理的结论 |

## 反假设对抗（Phase 3 专用）

当用户否认偏误或归因浅薄时触发（Phase 2b 不触发，避免对话失控）：

1. **抽替代假设 Y**：
   - 优先查 `cognitive-biases.md` 偏误相关性提示节的 seed 表，取与当前偏误**高相关**的偏误作 Y
   - 当前偏误**不在表内**时，按下方"替代假设生成规则"从**同族/邻近偏误**抽 Y
2. 问："如果这不是 X 而是 Y，证据各是什么？你怎么区分？"
3. 用户坚持原判断：
   - 第 1 次坚持 → 再追问一次证据
   - 第 2 次坚持且给出理由 → 收手，说"我查理问到这里——你坚持，那是你的决定，后果也归你"，**并把该未定分歧（X vs Y + 双方简述理由）记入笔记 `unresolved_disagreements`，供下次复盘 Phase 0 读回待验**
4. 反假设对抗不是价值判断，是归因检验；可以质疑归因，不评价人品

**替代假设生成规则（反假设对抗兜底）**：seed 表查不到当前偏误时——
1. 先找**同族**：与当前偏误认知机制同源的偏误（如偏乐观族 over-optimism / availability-misweighing / excessive-self-regard；偏一致性族 inconsistency-avoidance / doubt-avoidance / commitment-consistency）
2. 再找**邻近**：与当前偏误在同类决策环节常共现的偏误，或复盘元偏误 hindsight-bias / outcome-bias
3. 均不可得 → 用必检 2 条纪律作替代假设（"这不是 X 偏误，而是超出了能力圈 / 当时根本没反演过"）

## Pass signal 总原则

任一层用户答不出或纯复读定义 → 标记"探索项"，不强行推进，说"这个问题确实需要时间想——我们先往下走，回头再来看"。
