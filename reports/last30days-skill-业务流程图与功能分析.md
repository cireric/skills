# last30days-skill 业务流程图与功能分析

## 一、项目概述

**last30days-skill** 是一个 Agent Skills 包，用于跨 Reddit、X/Twitter、YouTube、Hacker News、Bluesky、GitHub 等多个平台研究任何主题。可安装于 Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI 等 50+ Agent Skills 主机。

### 2.2 Pipeline 核心处理流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                         PIPELINE 核心处理流程                                 │
│                           (pipeline.py:run)                                  │

┌─────────────────┐

        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    PHASE 1: 并行检索 (ThreadPoolExecutor)                     │

        ├──────────────────┬──────────────────┬──────────────────┬─────────────
        ▼                  ▼                  ▼                  ▼
┌───────────────┐  ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│    Reddit     │  │   X/Twitter   │  │   YouTube     │  │  Hacker News  │
│ (keyless/SC)  │  │ (bird/xai/    │  │  (yt-dlp/SC)  │  │  (Algolia)    │
│               │  │  xurl/xquik)  │  │               │  │               │
└───────────────┘  └───────────────┘  └───────────────┘  └───────────────┘
        │                  │                  │                  │
        ├──────────────────┴──────────────────┴──────────────────┴─────────────
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│              归一化 + 评分 + 去重 (_normalize_score_dedupe)                   │
├─────────────────────────────────────────────────────────────────────────────┤
│  1. normalize.normalize_source_items() → SourceItem[]                       │
│  2. signals.annotate_stream() → local_relevance, freshness, engagement     │
│  3. signals.prune_low_relevance() → 丢弃低于阈值项                           │
│  4. dedupe.dedupe_items() → 近重复移除 (trigram Jaccard)                    │
│  5. snippet.extract_best_snippet() → 最佳证据窗口                            │
└─────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    PHASE 2: 补充搜索                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│  1. entity_extract.extract_entities() → 从 Phase 1 提取 @handles, subreddits│
│  2. bird_x.search_handles() → 搜索发现的 handles (weight 0.3)               │
│  3. 薄源重试: <3 items 的源用简化查询重试 (weight 0.3)                        │
└─────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    FUSION: 加权倒数排名融合 (fusion.py)                       │
├─────────────────────────────────────────────────────────────────────────────┤
│  weighted_rrf():                                                             │
│  • 跨所有 (subquery, source) 流的加权 RRF                                     │
│  • 每作者上限 (max 3 items/author)                                           │
│  • 多样性池 (min 2 items/qualifying source)                                  │
└─────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    RERANKING: LLM 重排序 (rerank.py)                          │
├─────────────────────────────────────────────────────────────────────────────┤
│  rerank_candidates():                                                        │
│  • LLM 评分相关性 (如有 provider)                                            │
│  • 实体缺失惩罚 (25 points)                                                  │
│  • 意图特定评分提示 (comparison, how_to, prediction 等)                       │
│  • score_fun(): 可选趣味评分                                                 │
└─────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    CLUSTERING: 聚类 (cluster.py)                              │
├─────────────────────────────────────────────────────────────────────────────┤
│  cluster_candidates():                                                       │
│  • 实体重叠聚类 (Jaccard on extracted entities)                              │
│  • MMR 代表选择 per cluster                                                 │
│  • 不确定性标签 (single-source, thin-evidence)                              │
└─────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    FINALIZE: 最终处理                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│  • 按 local_rank_score 排序, 重新去重                                        │
│  • Polymarket 主题/关键词过滤                                                │
│  • Digg 富化 (top X posts)                                                  │
│  • GitHub star 富化                                                          │
└─────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    REPORT 生成 (schema.py)                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│  Report: topic, date_range, clusters, ranked_candidates,                    │
│          items_by_source, errors_by_source, warnings, artifacts             │
└─────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    RENDERING: 输出渲染                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│  --emit=compact (默认): render.render_compact() → Markdown                  │
│  --emit=html: html_render.render_html() → HTML 页面                         │
│  --emit=json: JSON 序列化                                                    │
│  --emit=context: render.render_context() → 精简上下文                        │
└─────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│                    输出结构 (Compact/MD)                                      │
├─────────────────────────────────────────────────────────────────────────────┤
│  1. Badge: 🌐 last30days v{VERSION} · synced {DATE}                         │
│  2. 安全提示 (untrusted content)                                             │
│  3. 日期范围, 活跃源                                                          │
│  4. 警告 (thin evidence, concentrated sources, errors)                      │
│  5. <!-- EVIDENCE FOR SYNTHESIS --> 证据簇                                   │
│  6. 排名证据簇 (scores, uncertainty labels, items)                          │
│  7. 统计, 源覆盖表                                                            │
│  8. <!-- PASS-THROUGH FOOTER --> emoji-tree footer (LAW 5)                 │
```

## 四、SKILL.md 8 大法则 (LAWs)

这些是结构性锚点，每条都源于已记录的生产故障:

| LAW | 名称 | 内容 |
|---|---|---|
| **LAW 1** | Badge | 必须以 `🌐 last30days v{VERSION} · synced {DATE}` 开头 |
| **LAW 2** | Inline Links | 所有链接必须内联在证据中，禁止末尾 Sources 块 |
| **LAW 3** | Evidence Envelope | 证据必须在 `<!-- EVIDENCE FOR SYNTHESIS -->` 包裹中 |
| **LAW 4** | No Invention | 禁止编造标题/内容，只使用引擎返回的数据 |
| **LAW 5** | Footer Pass-Through | emoji-tree footer 必须原样传递 |
| **LAW 6** | Uncertainty Labels | 标注不确定性 (single-source, thin-evidence) |
| **LAW 7** | Model is Planner | 托管模型生成 `--plan` JSON，非引擎内部 planner |
| **LAW 8** | Canonical Boundary | 输出必须以 `<!-- END PASS-THROUGH FOOTER -->` 结束 |

## 六、关键架构洞察

1. **双系统设计**: SKILL.md 是面向 Agent 的契约，Python 引擎是实现。新引擎标志若无 SKILL.md 集成则不完整。

2. **托管模型即规划器 (LAW 7)**: 在推理模型路径上，模型生成 `--plan` JSON，引擎的内部 LLM planner 仅用于无头/Cron 路径。

3. **Reddit 多层管道最复杂**: 五个模块处理 Reddit，分层回退架构确保在 Reddit 封禁端点时优雅降级。

4. **X/Twitter 四后端独立**: Bird CLI (cookie)、xAI Grok API、xurl CLI (官方 API v2)、Xquik API - 根据可用凭证自动选择。

5. **ScrapeCreators API_KEY 是多源钥匙**: 解锁 TikTok、Instagram、Threads、Pinterest、Reddit 备份、YouTube 搜索回退 - 单一最具影响力的凭证。

6. **Comparison/vs-mode 并行分发**: 每个实体获得独立的 `pipeline.run()` 调用，配置隔离通过深拷贝实现。
